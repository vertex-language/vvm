# stablehlo

Package `stablehlo` is an in-memory intermediate representation (IR) for
StableHLO modules. It models the structure of a StableHLO translation unit —
module, functions, and SSA op bodies (including region-carrying ops like
`reduce` and `while`) — without any formatting logic. Text printing lives in
a separate sub-package.

StableHLO is an MLIR dialect, and it has *two* interchange forms: MLIR
textual assembly (`.mlir`) and **portable artifacts** (MLIR bytecode routed
through the versioned VHLO dialect). Only portable artifacts carry
StableHLO's 5-year backward / 2-year forward compatibility guarantees —
prettyprinted text explicitly does not. Producing portable artifacts
requires the VHLO conversion machinery that lives in libStablehlo, so v1 of
this package emits text only; pipe it through
`stablehlo-translate --serialize` (or the Python `serialize_portable_artifact`
API) to get a guaranteed-stable artifact. Decoding (parsing MLIR back into
the IR) is out of scope for v1.

Unlike PTX (flat instructions over virtual registers) and MSL (statements
over named variables), StableHLO is a pure **SSA value graph**: every op
consumes values and *returns* new ones, there are no destinations, no
mutation, and no jumps — control flow is expressed by ops that carry
**regions** (`reduce`, `while`, `if`, `case`, `sort`, …). The builder API is
shaped around that: emit methods return `Value`s.

```
github.com/vertex-language/vvm/gpu/ir/stablehlo                 # IR types (this package)
github.com/vertex-language/vvm/gpu/ir/stablehlo/encoding/text   # text printer (.mlir)
```

## Quick start

```go
import (
    "github.com/vertex-language/vvm/gpu/ir/stablehlo"
    "github.com/vertex-language/vvm/gpu/ir/stablehlo/encoding/text"
)

// 1. Create a module (defaults to the package's pinned opset version).
m := stablehlo.NewModule("vadd")

// 2. Build a function: C = max(A + B, 0)
tf := stablehlo.Tensor(stablehlo.F32, 1024)        // tensor<1024xf32>

f := stablehlo.NewFunc("main")
a := f.Params.Add(stablehlo.Param{Name: "arg0", Type: tf})
b := f.Params.Add(stablehlo.Param{Name: "arg1", Type: tf})
f.Results = []stablehlo.Type{tf}

cb := f.Code
sum  := cb.Add(a, b)                               // %0 = "stablehlo.add"(...)
zero := cb.Constant(stablehlo.Splat(0.0, tf))      // %1 = "stablehlo.constant"()
out  := cb.Maximum(sum, zero)                      // %2 = "stablehlo.maximum"(...)
cb.Return(out)

m.Funcs.Add(f)

// 3. Print as MLIR assembly.
src, err := text.NewPrinter(m).Print()
```

The snippet above produces (generic syntax; `WithPrettyFuncs(true)` gives the
compact `func.func` header instead):

```mlir
// Generated by vertex
module @vadd {
  "func.func"() <{function_type = (tensor<1024xf32>, tensor<1024xf32>) -> tensor<1024xf32>, sym_name = "main"}> ({
  ^bb0(%arg0: tensor<1024xf32>, %arg1: tensor<1024xf32>):
    %0 = "stablehlo.add"(%arg0, %arg1) : (tensor<1024xf32>, tensor<1024xf32>) -> tensor<1024xf32>
    %1 = "stablehlo.constant"() {value = dense<0.0> : tensor<1024xf32>} : () -> tensor<1024xf32>
    %2 = "stablehlo.maximum"(%0, %1) : (tensor<1024xf32>, tensor<1024xf32>) -> tensor<1024xf32>
    "func.return"(%2) : (tensor<1024xf32>) -> ()
  }) : () -> ()
}
```

Verify with `stablehlo-opt vadd.mlir`; produce a compatibility-guaranteed
artifact with `stablehlo-translate --serialize --target=<version> vadd.mlir`.

## Concepts

### Module

`Module` is the root of the IR. It corresponds to a single MLIR `module` op
and carries an optional symbol name, module-level attributes, functions, and
an advisory `TargetVersion`.

```go
m := stablehlo.NewModule("mymodel")   // module @mymodel { ... }
m.SetTargetVersion(stablehlo.V1_0)    // lint floor; also the suggested
                                      // --target for serialization
m.Attrs.Add(stablehlo.RawAttr("mhlo.num_partitions", "2 : i32"))
```

#### Opset version constants

StableHLO has **no in-source version syntax** — the version only becomes
material when text is serialized into a portable artifact, where the VHLO
dialect downgrades ops to the target version. The minor version is bumped on
every opset or serialization-format change (the log lives in
`VhloDialect.td`), so a small table of named constants would rot quickly.
Landmark constants are provided:

| Constant | Version  | Notes                                                  |
| -------- | -------- | ------------------------------------------------------ |
| `V0_9`   | `0.9.0`  | first forward/backward compatibility window            |
| `V1_0`   | `1.0.0`  | 5yr backward / 2yr forward guarantees begin             |

`Version` is a plain `{Major, Minor, Patch}` struct with a `GTE` comparison,
so any released version can be constructed directly:
`stablehlo.Version{1, 12, 0}`. `DefaultVersion` is the version this package
was last audited against and is what `NewModule` pins as the starting
`TargetVersion`; `TargetVersion` itself is advisory and used only by the
printer's linter (`Printer.WithLint(true)`), which cross-references two
internal tables — `opMinVersion` (per-op, e.g. `composite` → 0.19.0, `tan` →
1.4.0) and `elemMinVersion` (per element spelling, e.g. `si2`/`ui2` → 1.2.0,
the newer `f8E…`/`f4E…`/`f6E…` formats → 1.7.0/1.8.0, plus per-axis
quantization → 0.18.0).

> **No target-hardware directive.** StableHLO is deliberately
> hardware-neutral — a portability layer between frameworks (JAX, PyTorch,
> TensorFlow) and compilers (XLA, IREE). Hardware gating is the consumer's
> problem; the opset version is the only gate this package models.

### Values and SSA

`Value` is the central handle type: function parameters are values, and
every emit method returns one (or several). Values are immutable and
single-assignment — there is no register file to allocate from and no
variable to overwrite. The printer numbers results `%0, %1, …` in emission
order (parameters print as `%arg0, %arg1, …`, and region block arguments
continue that same counter), so numbering is deterministic by construction.

```go
x := cb.Add(a, b)             // x is a Value of the op's result
state, out := cb.RngBitGenerator(...)  // multi-result ops return multiple Values
```

Every `Value` knows its `Type` via `Value.Type()`, but this is bookkeeping,
not verification — see Design notes. `Value.IsValid()` reports whether a
`Value` was actually produced by a builder (the zero `Value` is invalid).

### Types

StableHLO has no first-class scalars: element types only occur inside
tensors, and scalar values are idiomatically 0-dimensional tensors
(`tensor<f32>`).

```go
// Element types
stablehlo.I1                                        // boolean
stablehlo.SI2, stablehlo.SI4, ... stablehlo.SI64    // signed ints
stablehlo.UI2, stablehlo.UI4, ... stablehlo.UI64    // unsigned ints
stablehlo.F16, stablehlo.F32, stablehlo.F64
stablehlo.BF16, stablehlo.TF32
stablehlo.F8E4M3, stablehlo.F8E4M3FN, stablehlo.F8E5M2, stablehlo.F8E3M4,
stablehlo.F8E4M3FNUZ, stablehlo.F8E5M2FNUZ, stablehlo.F8E4M3B11FNUZ
stablehlo.F4E2M1FN, stablehlo.F6E2M3FN, stablehlo.F6E3M2FN,
stablehlo.F8E8M0FNU                                 // MX microscaling formats
stablehlo.Complex(stablehlo.F32)                    // complex<f32>, F32 or F64 only

// Value types
stablehlo.Tensor(stablehlo.F32, 2, 3)               // tensor<2x3xf32>
stablehlo.Tensor(stablehlo.F32)                     // tensor<f32> (0-d scalar)
stablehlo.TensorDyn(stablehlo.F64, stablehlo.Dyn, 2) // tensor<?x2xf64>, readability alias for Tensor
stablehlo.Token                                     // !stablehlo.token
stablehlo.Tuple(t1, t2)                             // tuple<...> (HLO-ABI legacy)
```

Dynamic dimension sizes are spelled `stablehlo.Dyn` (prints `?`, usable with
either `Tensor` or `TensorDyn`). Shapes can be partially or fully dynamic but
never unranked.

Quantized tensors wrap a `QuantizedElement`:

```go
q := stablehlo.Quant(stablehlo.QuantizedElement{
    Storage:   stablehlo.SI8,
    Expressed: stablehlo.F32,
    Scales:    []float64{0.02},
    ZeroPoints:[]int64{16},
}, 16, 16)
// tensor<16x16x!quant.uniform<i8:f32, 0.02:16>>
```

Per-axis quantization sets `Dimension` (via `stablehlo.Axis(d)`) and
provides one scale/zero-point pair per slice — this prints the
`{scale:zp,...}` list form and is what the linter's "per-axis quantization"
feature check keys off. `StorageMin`/`StorageMax` add an optional storage
range (`!quant.uniform<i8<-128:127>:f32, ...>`). `TypeString` renders any
`Type` to its canonical MLIR spelling and is exported for tooling built on
top of the IR.

### Constants and attributes

Op *inputs* are values; op *attributes* are static metadata. Constant
tensors are built from Go data or splat values via `Literal`
(`Repr + " : " + Type`, e.g. `dense<0.0> : tensor<1024xf32>`):

```go
stablehlo.Splat(0.0, t)                    // dense<0.0> : tensor<...>
stablehlo.DenseF32([]float32{1, 2, 3}, t)  // dense<[1.0, 2.0, 3.0]>
stablehlo.DenseI64(...)  stablehlo.DenseBool(...)  stablehlo.DenseF64(...)
stablehlo.DenseHex(bytes, t)               // dense<"0x..."> for bulk weights
```

Attribute constructors cover the surface the typed ops need:

```go
stablehlo.I64Attr(1)  stablehlo.I32Attr(1)  stablehlo.BoolAttr(true)
stablehlo.F32Attr(1.5)  stablehlo.F64Attr(1.5)  stablehlo.StrAttr("foo")
stablehlo.I64Array(2, 1)                   // array<i64: 2, 1>
stablehlo.BoolArray(true, false)           // array<i1: true, false>
stablehlo.DenseI64Matrix([][]int64{...})   // dense<[[...],...]> : tensor<NxMxi64>,
                                            // used by replica_groups/padding/source_target_pairs
stablehlo.ConvDims("[b,0,1,f]x[0,1,i,o]->[b,0,1,f]") // #stablehlo.conv<...>
stablehlo.DotDims{LhsContract: []int64{1}, RhsContract: []int64{0}, ...}
stablehlo.GatherDims{...}   // OperandBatchingDims/StartIndicesBatchingDims are
stablehlo.ScatterDims{...}  // omitted unless set (StableHLO >= 1.1)
stablehlo.ChannelHandle{Handle: 1, Type: 0}
stablehlo.SymRef("my_func")                // @my_func, for composite/custom_call
stablehlo.RawAttr("mhlo.sharding", `"{replicated}"`)  // escape hatch for unspecced attrs
stablehlo.UnitAttr("some_flag")            // prints as the bare name, no `= value`
stablehlo.AnyAttr(v)                       // coerces a plain Go int/float/bool/
                                            // string/[]int64/Attr to an Attr
```

Enums are typed constants: `stablehlo.CmpLT`, `stablehlo.CmpEQ`, … with
`stablehlo.CompareFloat` / `CompareTotalOrder` / `CompareSigned` /
`CompareUnsigned`; `stablehlo.RngUniform` / `RngNormal`; `stablehlo.RngDefault`
/ `RngThreeFry` / `RngPhilox` (for `RngBitGenerator`); `stablehlo.NoTranspose`
/ `TransposeT` / `Adjoint` (for `triangular_solve`); `stablehlo.FftFFT` /
`FftIFFT` / `FftRFFT` / `FftIRFFT`.

### Functions

`Func` (→ `func.func`) has a name, parameters, result types, and a
`*CodeBuilder` body. A `nil` `Code` body is a declaration only and prints as
`func.func private @f(...)` (generic form) with no region — useful for
`composite` decompositions or `custom_call` `called_computations` that are
declared but defined elsewhere.

```go
f := stablehlo.NewFunc("main")
f.Params.Add(stablehlo.Param{Name: "arg0", Type: tf})
f.Results = []stablehlo.Type{tf}
f.Private = true                    // sym_visibility = "private"
f.ArgAttrs[0] = stablehlo.RawAttr("mhlo.sharding", `"{replicated}"`)
f.ResAttrs[0] = stablehlo.RawAttr("mhlo.sharding", `"{replicated}"`)
```

`ParamList.Add` both records the parameter and returns its SSA `Value`;
`ParamList.All()` / `.Values()` / `.Len()` expose the recorded parameters.
Helper functions referenced by `composite` decompositions or `custom_call`
`called_computations` are ordinary `Func`s added to the module; symbol
references are spelled `stablehlo.SymRef("my_op")`.

### CodeBuilder

Append-only (`CodeBuilder.Ops()` returns emitted ops in emission order).
Emit methods take `Value` (and attribute) arguments and return result
`Value`s. Result types are computed by *shape propagation* for the easy
cases (elementwise ops inherit their operand type via internal `unary`/
`binary` helpers) and taken as an explicit argument where inference would
amount to reimplementing the spec (`dot_general`, `convolution`, `reduce`,
…) — this package never type-checks, it just records what you tell it.

#### Op families (representative)

```go
// Elementwise unary — result type mirrors the operand
cb.Abs(x) cb.Ceil(x) cb.Floor(x) cb.Cosine(x) cb.Sine(x) cb.Tan(x) cb.Tanh(x)
cb.Exponential(x) cb.ExponentialMinusOne(x) cb.Log(x) cb.LogPlusOne(x)
cb.Logistic(x) cb.Negate(x) cb.Not(x) cb.Rsqrt(x) cb.Sqrt(x) cb.Cbrt(x)
cb.Sign(x) cb.Popcnt(x) cb.Clz(x) cb.RoundNearestEven(x) cb.RoundNearestAfz(x)
cb.IsFinite(x)                              // result element type forced to i1

// Elementwise binary / ternary — result type mirrors the lhs
cb.Add(a, b) cb.Subtract(a, b) cb.Multiply(a, b) cb.Divide(a, b) cb.Remainder(a, b)
cb.Maximum(a, b) cb.Minimum(a, b) cb.Power(a, b) cb.Atan2(a, b)
cb.And(a, b) cb.Or(a, b) cb.Xor(a, b)
cb.ShiftLeft(a, b) cb.ShiftRightArith(a, b) cb.ShiftRightLogical(a, b)
cb.Compare(stablehlo.CmpLT, a, b)          // + CompareWith(dir, compareType, a, b)
cb.Select(pred, onTrue, onFalse)            // result type follows onTrue
cb.Clamp(min, x, max)                       // result type follows x

// Type conversion
cb.Convert(t, x)                            // element-type conversion
cb.BitcastConvert(t, x)
cb.UniformQuantize(qt, x) / cb.UniformDequantize(t, x)
cb.Reshape(t, x)

// Shape & data movement
cb.BroadcastInDim(t, x, dims)               // broadcast_dimensions = array<i64: ...>
cb.Transpose(t, x, perm)
cb.Slice(t, x, starts, limits, strides)
cb.DynamicSlice(t, x, startIdxValues, sizes)
cb.DynamicUpdateSlice(x, update, startIdxValues)  // result type follows x
cb.Concatenate(t, dim, xs...)
cb.Pad(t, x, padVal, low, high, interior)
cb.Reverse(t, x, dims)
cb.Iota(t, dim)
cb.Gather(t, operand, startIndices, gatherDims, sliceSizes)

// Linear algebra
cb.DotGeneral(t, lhs, rhs, dotDims)
cb.Convolution(t, lhs, rhs, convCfg)        // strides/padding/dilation/dims struct;
                                             // feature/batch group counts default to 1
cb.Cholesky(t, a, lower)
cb.TriangularSolve(t, a, b, cfg)            // cfg.TransposeA defaults to NoTranspose
cb.Fft(t, x, fftType, fftLength)

// Region-carrying ops — bodies are built by callback (see below)
cb.Reduce(...) / cb.ReduceN(...) cb.ReduceWindow(...) cb.Map(...) cb.Sort(...)
cb.SelectAndScatter(...) cb.Scatter(...)
cb.While(...) cb.If(...) cb.Case(...)

// Distribution / collectives
cb.AllReduce(...) cb.AllGather(...) cb.AllToAll(...) cb.ReduceScatter(...)
cb.CollectivePermute(...) cb.CollectiveBroadcast(...)
cb.PartitionId() cb.ReplicaId()             // both return tensor<ui32>
cb.Infeed(resultTypes, token, config)       // returns (results..., token)
cb.Outfeed(inputs, token, config)           // returns the result token
cb.Send(inputs, token, ch, isHostTransfer)  // returns the result token
cb.Recv(resultTypes, token, ch, isHostTransfer) // returns (results..., token)
cb.AfterAll(tokens...) cb.CreateToken()
cb.OptimizationBarrier(xs...)               // results mirror operand types

// Extensibility
cb.CustomCall(resultTypes, "target", inputs, opts)  // backend_config, side effects,
                                                     // called_computations, api_version, extra attrs
cb.Composite(resultTypes, "ns.my_op", inputs, stablehlo.SymRef("my_op_impl"), attrs)

// Misc
cb.Constant(literal)
cb.Scalar(v, e)                             // convenience: 0-d splat constant from a Go scalar
cb.Rng(t, a, b, stablehlo.RngUniform)       // shape operand synthesized from t's static dims
cb.RngBitGenerator(stateT, outT, alg, initialState)  // returns (outputState, output)
cb.Tuple(xs...) / cb.GetTupleElement(x, index)  // HLO-ABI legacy
cb.Return(xs...)                              // func.return at function level,
                                               // stablehlo.return inside a region
cb.Comment("trailing note")                   // attaches to the last emitted op
cb.RawAttrOnLast("mhlo.frontend_attributes", "{...}")  // attaches a raw attr to the last op
```

#### Regions

Ops with bodies take a Go closure that receives a fresh `RegionBuilder` and
the region's block arguments; the closure must end with `rb.Return(...)`
(→ `stablehlo.return`). Region blocks are single-entry — StableHLO has no
jump ops, so a region is exactly one block.

```go
zero := cb.Constant(stablehlo.Splat(0.0, stablehlo.Tensor(stablehlo.F32)))

sum := cb.Reduce(
    stablehlo.Tensor(stablehlo.F32, 1024),   // result type
    []stablehlo.Value{x}, []stablehlo.Value{zero},
    []int64{1},                              // dimensions
    func(rb *stablehlo.RegionBuilder, args []stablehlo.Value) {
        rb.Return(rb.Add(args[0], args[1]))
    })
```

`While` takes two closures (cond, body) whose block-argument types mirror
the init values; `If` takes two closures with no block arguments; `Case`
takes a slice of branch closures, also with no block arguments. `Reduce`,
`ReduceWindow`, and `Scatter` bodies receive doubled scalar arguments
(accumulators/current values, then elements/updates); `Sort`'s comparator
receives two scalars per input; `Map`'s body receives one scalar per input.
Region block-argument types are always derived this way or supplied
directly by the caller — no inference.

```go
res := cb.While([]stablehlo.Value{init},
    func(rb *stablehlo.RegionBuilder, args []stablehlo.Value) { // cond
        rb.Return(rb.Compare(stablehlo.CmpLT, args[0], limit))
    },
    func(rb *stablehlo.RegionBuilder, args []stablehlo.Value) { // body
        rb.Return(rb.Add(args[0], one))
    })
```

#### Raw escape hatch

The opset is ~100 specced ops plus a long tail of attribute variations, and
StableHLO programs in the wild also carry unspecced attributes
(`mhlo.sharding`, layouts, frontend attributes). Anything not covered by a
typed emit goes through:

```go
v := cb.Raw(resultTypes, `"stablehlo.dynamic_gather"(%s, %s, %s) {...}`, x, idx, sizes)
cb.RawAttrOnLast("mhlo.frontend_attributes", "{...}")
```

`Raw` ops still participate in SSA numbering (operand `Value`s are
interpolated by name, results are fresh `Value`s). Typed builders for
op families get promoted from `Raw` as their own files (`collectives.go`,
`control.go`, `linalg.go`, …) without touching the core.

## Text printing

```go
src, err := text.NewPrinter(m).Print()
```

The printer emits **generic MLIR syntax** (`"stablehlo.add"(%0, %1) : ...`)
by default rather than the dialect's pretty forms. This is deliberate: the
spec itself sticks to generic syntax because prettyprinter output can change
across releases, and byte-stability is a design requirement here.
`WithPrettyFuncs(true)` opts in to the compact `func.func` header form shown
in the quick start (arguments inline) while keeping op bodies generic.

Output ordering: header comment, `module` attributes, functions in insertion
order. Within a body: ops in emission order, `%0, %1, …` numbering (multi-
result ops number as `%N:K` with `%N#0, %N#1, …` for individual results),
2-space MLIR-conventional indentation.

`Printer` options:

```go
p := text.NewPrinter(m).
    WithComments(true).                    // trailing // comments from Op.Comment
    WithHeader("Generated by vertex 0.4"). // "" disables the header
    WithLint(true)                         // advisory version-gate warnings

src, err := p.Print()
notes := p.Warnings()   // e.g. "tan requires StableHLO >= 1.4.0 (target is 1.0.0)"
```

`Print` returns an error only for structurally invalid modules (a `Value`
used across function boundaries, a region closure that never called
`Return`, a `Func` with results but no terminator). Lint findings are
warnings, never errors, and are deduplicated by message within a single
`Print` call.

## Design notes

**Text is the v1 wire format; artifacts are libStablehlo's.** StableHLO's
compatibility guarantees (5yr backward / 2yr forward) attach only to
portable artifacts — MLIR bytecode produced through the VHLO versioned
dialect — and explicitly *not* to prettyprinted text. Reimplementing VHLO's
per-version op snapshots and the MLIR bytecode encoder here would mean
chasing every minor release; instead the printer produces valid `.mlir` and
`stablehlo-translate --serialize --target=X` owns the guarantee. If a native
`encoding/artifact` ever lands, it will shell out to or bind libStablehlo
rather than reimplement it.

**SSA values, not registers, not statements.** Emit methods *return*
`Value`s. There is no register file (contrast `ptx`) and no mutable named
locals (contrast `msl`) — one op, one set of immutable results.
Deterministic numbering falls out of emission order, covered by
`TestDeterminism`.

**Regions, not labels.** Control flow is structured op nesting (`while`,
`if`, `case`, reduction bodies). No jumps exist in the opset, so no labels
and no offset resolution exist in the IR.

**No inference, no verification.** This package does not run type
inference, does not check the spec's per-op constraints (the spec defines
verifiers and type inference for every op — implementing them is a compiler
project, not an IR project), and does not validate quantization parameters.
Result types are caller-supplied wherever they aren't trivially the operand
type. Garbage in, garbage out — `stablehlo-opt` is the verifier of record.

**Version gating is advisory.** `TargetVersion` exists so callers can pick
a serialization floor; the printer optionally warns via `WithLint(true)`
when an emitted op or type postdates it (using the `VhloDialect.td` version
log as reference, mirrored in the package's `opMinVersion`/`elemMinVersion`
tables), with warnings retrievable from `Printer.Warnings()`. Whether a
program actually downgrades to that version is decided by
`stablehlo-translate`, not by this package.

**Typed core, raw periphery.** The specced elementwise / shape / linalg /
control-flow / collective surface gets typed emit methods; unspecced
attributes, exotic dynamism ops, and anything mid-migration in the opset
start as `Raw` and get promoted per-family as needed.

**Convenience coercion.** Attribute positions accept plain Go ints, floats,
bools, strings, and `[]int64` alongside `Attr` values via `AnyAttr`, and
scalar literals coerce to 0-d splat constants where a `Value` is expected
via `cb.Scalar(1.0, F32)`. This is the one place ergonomics won over strict
typing; operand positions remain typed `Value`.
